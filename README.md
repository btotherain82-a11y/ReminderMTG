# Commander Companion

Play Commander with your friends using the Windows or Mac desktop app.

## Download the game

**[Go to the latest release](https://github.com/btotherain82-a11y/ReminderMTG/releases/latest)**

On the release page, open **Assets** and download the ZIP for your computer:

- **Windows:** `Commander-Companion-Windows.zip` — unzip it, then open `Commander Companion.exe`. Keep the EXE, data folder, and other files together.
- **Mac:** `Commander-Companion-Mac.zip` — unzip it, then open `Commander Companion.app`. This Mac build has not yet been tested on a Mac and is not signed by Apple, so macOS may ask you to approve it.

You do not need a GitHub account to download the game. The `.sha256` files are for the in-app updater; you do not need to download them for a first install. **Do not choose “Source code (zip)” or “Source code (tar.gz)”**—those are not the playable app.

Already have Commander Companion installed? Open the app and choose **Check for Updates** on the start screen.
